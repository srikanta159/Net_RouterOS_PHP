# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within this repository, please report it responsibly:

1. **Do not disclose the issue publicly** in an open GitHub issue or public forum.
2. Email the maintainer directly or submit a private security advisory via GitHub's [Security Advisories](https://github.com/srikanta159/Net_RouterOS_PHP/security/advisories).
3. Please include:
   - A description of the vulnerability and potential impact.
   - Steps or a minimal proof of concept to reproduce the issue.
   - Affected versions and environments (PHP and RouterOS versions).

We will acknowledge receipt within 48 hours and work with you to test and release a security fix in a timely manner.
